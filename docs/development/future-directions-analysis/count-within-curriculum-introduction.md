# Count-Within Curriculum Introduction

## Why Deferred

Count-within is a useful next step for students who are already composing boolean thresholds, but this packet was written during the pilot cycle. Adding a new guided lesson now would risk pulling mid-arc students into a new concept before the current project arc has settled. The block can land safely; the teaching sequence can wait.

## Introduction Level Proposal

Introduce the first count-within lesson somewhere in L23-L27, after students already know runner index, compare, and at least one compound boolean structure. A short checkpoint could ask them to count nearby enemies or allies and decide whether to advance or retreat based on a threshold. The win condition should reward threshold reasoning, not just a direct movement pattern.

## Bug Hunt Proposal

A good bug hunt would use the wrong threshold comparison, such as `> 2` where the lesson expects `>= 2`, or an off-by-one distance choice. The shape should be familiar: a shared strategic program where the count block is present but the comparison logic is wrong, so students learn to inspect the numeric reasoning instead of copying a finished answer.

## Prediction Level Proposal

A prediction checkpoint could show a labeled board and ask whether a count-threshold branch will evaluate true before students run the program. This is a good fit for the Strategy Brain arc because students already have enough vocabulary to reason about nearby threats without needing a new board mechanic.

## Reference Solution Refresh

Likely candidates for a future reference-solution cleanup are `closest-threat`, `how-far-away`, `two-conditions-at-once`, `this-or-that`, `flip-the-answer`, and `full-team-tactics` in Strategy Brain, plus `one-program-two-allies`, `first-two-defend`, `escort-the-carrier`, and `advanced-scrimmage` in Team Strategy Script. Count-within is not required for any of them, but some of their guard logic would read more clearly with aggregate sensing.

## Triggers

Pick this work up if teachers report that students are building long chains of local sensors to approximate "two or more nearby" logic, or if classroom evidence shows that the project arc would benefit from a named aggregate-sensing checkpoint. That would be the signal to author the lesson sequence rather than only surfacing the block.
