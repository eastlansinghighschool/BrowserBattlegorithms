# Cohort Usage Data Dictionary

This document describes the schema and fields of the 6 normalized tables generated by the cohort usage analysis pipeline.

Generated tables live in the git-ignored local path:
`local/usage-cohorts/<cohort-id>/anonymized/json/`
`local/usage-cohorts/<cohort-id>/anonymized/csv/`

Note: For identity-stripped cloud exports, `identityMap.details[].studentName` is empty and longitudinal linking relies on the filename.

---

## Table 1: `exports`
Tracks general metadata about each processed student export file.

| Field | Type | Description | Illustrative Example |
|---|---|---|---|
| `exportId` | String | Stable anonymous identifier assigned to the export file. | `"export-001"` |
| `fileLabel` | String | A sanitized generic filename. | `"file_001.json"` |
| `hashStatus` | String | Status indicating if the export payload hash is verified. | `"verified hash"` |
| `exportedAt` | String | ISO 8601 timestamp representing when the export was created. | `"2026-05-13T10:15:00.000Z"` |
| `totalEvents` | Integer | Total number of recorded events in the file. | `45` |
| `totalSnapshots` | Integer | Total number of workspace XML snapshots. | `3` |
| `sessionSpanMinutes` | Integer | Total estimated duration of the student session in minutes. | `15` |
| `needsReview` | Integer | Binary flag (0 or 1) indicating if review signals were triggered. | `0` |
| `reviewFlags` | String | Semicolon-separated list of triggered warning codes. | `"integrity_mismatch; missing_level_id"` or `null` |

---

## Table 2: `events`
A normalized subset of event metadata representing actions, states, and operations performed during the session.

| Field | Type | Description | Illustrative Example |
|---|---|---|---|
| `exportId` | String | Matches `exportId` in the `exports` table. | `"export-001"` |
| `eventIndex` | Integer | 0-based index of the event within the export file sequence. | `0` |
| `eventType` | String | Type of event (e.g. `level_started`, `level_completed`, `workspace_snapshot`). | `"level_started"` |
| `timestamp` | String | ISO 8601 timestamp when the event occurred. | `"2026-05-13T10:00:02.000Z"` |
| `levelId` | String | The identifier of the active level, if applicable. | `"move-to-target"` or `null` |
| `levelTitle` | String | The human-readable title of the active level, if applicable. | `"Move to target"` or `null` |
| `levelOrder` | Integer | 1-based order of the level in the curriculum progression. | `1` or `null` |
| `result` | String | The completion outcome: `"PASSED"`, `"FAILED"`, or `null`. | `"PASSED"` or `null` |
| `turnNumber` | Integer | Active turn number when the event occurred. | `3` or `null` |
| `turnsSpent` | Integer | Total turns spent (only for completed runs). | `3` or `null` |
| `attemptNumber` | Integer | The attempt sequence index (only for starts). | `1` or `null` |
| `modeView` | String | The UI mode view (e.g. `"GUIDED_LEVELS"`). | `"GUIDED_LEVELS"` or `null` |

---

## Table 3: `guided_attempts`
Parsed level execution runs, identifying start, completion status, and time spent per attempt.

| Field | Type | Description | Illustrative Example |
|---|---|---|---|
| `exportId` | String | Matches `exportId` in the `exports` table. | `"export-001"` |
| `levelId` | String | The level ID. | `"move-to-target"` |
| `levelOrder` | Integer | 1-based curriculum sequence order of the level. | `1` |
| `attemptNumber` | Integer | 1-based attempt counter for this level. | `1` |
| `startAt` | String | ISO 8601 start timestamp. | `"2026-05-13T10:00:02.000Z"` |
| `endAt` | String | ISO 8601 end timestamp. | `"2026-05-13T10:01:00.000Z"` |
| `result` | String | Result of the attempt: `"PASSED"`, `"FAILED"`, `"interrupted"`, `"boundary"`, `"session_end"`. | `"PASSED"` |
| `turns` | Integer | Total gameplay turns spent in this attempt. | `3` |
| `durationMs` | Integer | Duration of the attempt in milliseconds. | `58000` |
| `durationLabel` | String | Formatted duration description. | `"58s approx"` |
| `durationReliable` | Integer | Binary flag (0 or 1) indicating if start and end timestamps are valid. | `1` |

---

## Table 4: `guided_level_rollup`
Aggregated progress metrics grouped by export file and level ID.

| Field | Type | Description | Illustrative Example |
|---|---|---|---|
| `exportId` | String | Matches `exportId` in the `exports` table. | `"export-001"` |
| `levelId` | String | The level ID. | `"move-to-target"` |
| `levelTitle` | String | Level title. | `"Move to target"` |
| `levelOrder` | Integer | 1-based curriculum sequence order of the level. | `1` |
| `startedCount` | Integer | Number of times this export started this level. | `2` |
| `completedCount` | Integer | Number of times this export completed this level. | `2` |
| `passedCount` | Integer | Number of passes recorded. | `1` |
| `failedCount` | Integer | Number of failures recorded. | `1` |
| `revisits` | Integer | Number of return visits (`startedCount - 1` if > 0). | `1` |
| `turnsSpent` | Integer | Cumulative gameplay turns spent on this level. | `5` |
| `durationMs` | Integer | Cumulative duration spent on this level in milliseconds. | `124000` |
| `durationLabel` | String | Cumulative formatted duration. | `"2m 4s approx"` |
| `reached` | Integer | Binary flag (0 or 1) indicating if the student reached the level. | `1` |
| `passed` | Integer | Binary flag (0 or 1) indicating if the student ever passed the level. | `1` |

---

## Table 5: `class_level_rollup`
Cohort-wide aggregated statistics for each level in the curriculum.

| Field | Type | Description | Illustrative Example |
|---|---|---|---|
| `levelId` | String | The level ID. | `"move-to-target"` |
| `levelTitle` | String | Level title. | `"Move to target"` |
| `levelOrder` | Integer | 1-based curriculum sequence order of the level. | `1` |
| `reachedCount` | Integer | Number of export files that reached this level. | `25` |
| `passCount` | Integer | Number of export files that passed this level. | `24` |
| `failCount` | Integer | Number of export files that failed but never passed this level. | `1` |
| `startedOnlyCount` | Integer | Number of exports that started but never completed this level. | `0` |
| `medianAttemptsToFirstPass` | Number | Median starts required before obtaining the first PASS. | `1.5` |
| `medianTurnsOnPassedAttempts` | Number | Median turns spent on successful passed attempts. | `3.0` |
| `revisitCount` | Integer | Total revisits across all export files on this level. | `12` |

---

## Table 6: `export_progress`
Progression milestones, highest achievements, navigation styles, and review flags for each export file.

| Field | Type | Description | Illustrative Example |
|---|---|---|---|
| `exportId` | String | Stable anonymous identifier. | `"export-001"` |
| `highestReachedId` | String | ID of the highest curriculum level reached in this export. | `"enemy-nearby"` |
| `highestReachedOrder` | Integer | 1-based curriculum order of the highest reached level. | `13` |
| `highestPassedId` | String | ID of the highest required level passed by the student. | `"move-to-target"` |
| `highestPassedOrder` | Integer | 1-based curriculum order of the highest passed required level. | `1` |
| `highestPassedChallengeLabel` | String | Formatted label of the highest passed challenge level. | `"Challenge 22: Show What You Know"` |
| `latestGuidedActivityType` | String | Event type of the export's latest guided activity. | `"level_started"` |
| `latestGuidedActivityLevelId` | String | Level ID of the export's latest guided activity. | `"optional-random-lab"` |
| `revisitCount` | Integer | Total backtracks / revisits performed across all levels. | `4` |
| `needsReview` | Integer | Binary flag (0 or 1) indicating if review flags are present. | `0` |
| `reviewFlags` | String | Semicolon-separated list of warning codes. | `"integrity_mismatch"` or `null` |
