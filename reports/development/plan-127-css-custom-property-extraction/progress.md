## Wiring model and zero-visual-change evidence

The source transformation uses the following shape:

```css
:root {
  --c-slate: 36 64 74;
}

/* Alpha stays at the declaration site. */
.example {
  color: rgb(var(--c-slate));
  box-shadow: 0 2px 4px rgb(var(--c-slate) / 0.12);
}
```

Thus `rgba(36,64,74,0.12)` becomes `rgb(var(--c-slate) / 0.12)`, while `#24404a` becomes
`rgb(var(--c-slate))`. Transparent declarations become `rgb(var(--c-black) / 0)` so their
resolved value remains transparent black.

The per-declaration wiring test does not compare replacement text. For every baseline file,
declaration ordinal, and occurrence ordinal, it resolves the token's root channels plus the
call-site alpha and compares the resulting canonical color to the baseline. It also requires the
token selected for the expected RGB triple and requires all out-of-scope values to remain raw and
byte-identical.

The deliberate two-token call-site swap test was demonstrated to fail with this message:

```text
src/assets/styles/help.css declaration 33 occurrence 0: token --c-ocean resolved to rgba(59,111,144,0.12); expected rgba(36,64,74,0.12)
```

The test intentionally swaps two Help call sites rather than merely swapping root declarations,
so it proves that file/declaration/occurrence wiring is checked.

## Canonicalizer contract

`canonicalizeCssColor` is named and directly tested. It canonicalizes lowercase/expanded opaque
hex, numeric `rgb()`/`rgba()`, `white`, and `transparent`, and returns `null` for dynamic
`var()`/`currentColor` expressions.

The canonicalizer now fails closed rather than rounding distinctions it cannot represent exactly:

- RGB channels must resolve to exact integer channels; fractional channels and percentages that
  produce fractional channels are rejected.
- Alpha, hue, saturation, and lightness values that would change under the ten-decimal canonical
  representation are rejected rather than rounded.
- Four- and eight-digit alpha-bearing hex values are rejected rather than converting the binary
  alpha byte through a lossy decimal approximation. The migration helper also refuses them.
- Malformed numeric suffixes are rejected.

The focused tests cover fractional RGB, fractional percentage RGB, high-precision alpha,
alpha-bearing hex, and high-precision HSL hue/saturation/lightness. Existing source values are
within the supported exact representation, so the baseline re-extracts identically with the fixed
canonicalizer.
